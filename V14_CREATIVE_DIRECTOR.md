# V14 Creative Director
V14 is a major creative-direction upgrade over V13.1.

- Hook Director 2.0: a short visual promise without consuming the payoff.
- Dynamic Editing: compress low-progress moments and add only a few content-driven punch-ins.
- AI Voice Director: generates a short Vietnamese voice plan (0-3 lines), never constant narration.
- Text + Voice coordination: on-screen text should emphasize keywords instead of repeating narration.
- Payoff Director 2.0: reduce visual noise before the final reward and let the reveal breathe.
- Visible Delta Guard: V14 is expected to feel materially different from a baseline cut, without effect spam.

The voice plan is exported as JSON + SRT so a local/cloud TTS provider can synthesize it. V14 does not pretend a voice exists when no TTS engine is configured.
